# Proposal

## Why

Проекту нужна расширяемая основа фронтенда, которая отдаёт готовый React HTML через Express, загружает JavaScript только для интерактивных островов и позволяет выпускать микрофронтенды независимо. Репозиторий пока содержит только OpenSpec; существующих приложений и спецификаций нет.

## What Changes

- Создать TypeScript workspace с пакетами контрактов, серверного и браузерного runtime, интеграции Rsbuild и демонстрационными приложениями.
- Реализовать Express host с серверной композицией страницы из независимо развёртываемых микрофронтендов.
- Определить версионированный release manifest и HTTP-контракт рендеринга: серверный HTML и клиентские ресурсы принадлежат одному релизу.
- Реализовать отдельные React roots для островов с политиками `load`, `visible`, `idle`, `never`, без гидратации всей страницы.
- Добавить два микрофронтенда: каталог с фильтром и счётчик корзины с локальным состоянием; реальные покупки и backend магазина не входят в объём.
- Обеспечить независимые сборки, локальную разработку, проверку production-артефактов, обработку отказов и документированный выпуск/откат.

## Capabilities

### New Capabilities

- `ssr-composition`: Express host, маршруты, серверная композиция, изоляция ошибок и запросов.
- `islands-hydration`: декларация островов, безопасная передача props, выборочная гидратация и жизненный цикл.
- `microfrontend-releases`: контракты модулей, независимые релизы, совместимость и согласованность server/client.
- `frontend-tooling`: Rsbuild сборки, workspace, dev/prod команды и два демонстрационных приложения.

### Modified Capabilities

Нет.

## Impact

Добавляются новые пакеты и приложения; существующих API для миграции нет. Базовые зависимости: React, React DOM, Express, Rsbuild, TypeScript; тестовые инструменты выбираются при реализации и фиксируются lockfile. Развёртывание включает host и два отдельных Express-сервиса с неизменяемыми клиентскими ресурсами. В первой версии не требуются Module Federation, SPA-router, React Server Components, потоковая передача HTML, авторизация, общий бизнес-store или облачная инфраструктура.
